Project Abstract

Built for clear control over a physical WSN testbed.

Libraries / Tools

Technical stack required for the system.

Python / Django Backend APIs for nodes, experiments, deployments, users, and stored results.
JavaScript / React Frontend interface for configuration, monitoring, charts, reports, and controls.
WebSockets Live telemetry channel for node status, packet flow, latency, and gateway updates.
PostgreSQL / MongoDB Structured experiment data in PostgreSQL, with MongoDB optional for raw sensor payloads.
Hardware interfaces: serial / USB Gateway connection for node programming, telemetry collection, and firmware deployment.
Data visualization libraries Charts for PDR, latency, RSSI, throughput, energy use, and experiment comparisons.
Authentication system Role-based access for administrators, operators, and viewers to protect remote testbed functions.

Technical Architecture

How the complete WSN interface is designed to work.

React Website UI Configuration, charts, logs, access screens
Django REST API Nodes, experiments, deployments, results
WebSocket Layer Live telemetry and network status updates
Database + Hardware PostgreSQL/MongoDB and serial/USB adapters

Protocols

HTTP APIs handle configuration and reports, while WebSockets support low-latency telemetry updates.

Data Flow

Sensor nodes send readings to the gateway, the backend stores them, and the website visualizes status.

Hardware Boundary

Serial/USB operations are isolated so firmware flashing and telemetry parsing stay maintainable.
