# WSN Testbed Management Interface

Published website files for the WSN Testbed Management Interface.

## Live Link

After GitHub Pages is enabled for this repository, the site will open at:

https://abhinay-reddy1107.github.io/WSN/

## GitHub Pages Setting

Open the repository settings and enable:

- Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

The site can take a minute or two to become live after saving.
